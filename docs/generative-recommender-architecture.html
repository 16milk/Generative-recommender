01. 端到端总览

Training ⇄ Serving Feedback Loop

02. 六层模块职责

Modular Architecture
01

数据层

把点式推荐日志转换为用户级序列学习问题。

  • Pointwise baseline
  • Listwise 主线
  • Long/Short Seq
  • 流式 joiner + 批式回溯
02

Tokenizer

把物品映射为可生成的多级语义 ID。

  • 多模态 Emb
  • 行为协同 Emb
  • RQ-Kmeans / RQ-VAE
  • 均匀度与 path 评估
03

模型层

以用户序列为上下文，自回归生成 SID。

  • Encoder-Decoder baseline
  • Decoder-heavy / HSTU
  • SID Decoder
  • Reward Heads
04

训练层

先学习行为模式，再做业务偏好对齐。

  • Next-token CE
  • Reward weighted SFT
  • DPO / GRPO
  • Format + Diversity Reward
05

Serving

生成、检索、融合和下游排序协同。

  • Beam / Gumbel TopK
  • SID 倒排 / ANN
  • Snake / Score Merge
  • Guarantee / AB
06

监控治理

保障数据、SID、模型和链路稳定。

  • 特征覆盖与一致性
  • SID 命中与空结果率
  • 链路通过率
  • 效果与延迟看板

03. 数据与 SID 设计

Sequence + Semantic ID

样本结构

字段说明
user_profile稳定用户画像，作为普通特征或 profile tokens。
long_seq长期正向行为序列，表达稳定兴趣。
short_seq近期行为窗口，side info 更全，label 更丰富。
target_seq待回归的 gid/sid/action/timestamp 序列。
mask按 req_time 去除重复训练片段。

SID 质量雷达

维度指标目的
均匀度Gini / 熵 / 利用率避免 codebook collapse。
Path覆盖率 / 挂载数 / 孤点簇控制空结果与 collision。
语义i2i hitrate / 重构 hitrate保证相似物品共享结构。
在线SID→GID 命中 / 召回占比验证 serving 可用性。

04. 模型与训练闭环

Pretrain First, Align Later

Pre-training

  • Listwise / Pointwise next SID prediction
  • CE loss + action/reward weight
  • 目标是学习用户兴趣迁移和 SID 空间结构

Post-training

  • Rank / VT / UA reward 回流
  • DPO / GRPO / listwise preference
  • 提升 pass@1、有效性与业务偏好

Scale Path

  • Decoder-heavy / Decoder-only
  • HSTU / MoE / SID Decoder
  • 更长序列、更大词表、更大 beam

06. 演进路线图

P0 → P4
P0

离线闭环

样本、SID、baseline 模型、HR@K/MRR、SID→GID 反查全部跑通。

P1

可服务化

生成 SID、检索 GID、merge、延迟和空结果率可控。

P2

规模化

listwise 主线、长序列、GPU serving、beam/cache 优化，观察 scale trend。

P3

偏好对齐

引入 rank/VT/UA reward，构造 trajectory，尝试 DPO/GRPO。

P4

统一推荐

召回、排序、重排逐步融合，走向 one model serve all。
